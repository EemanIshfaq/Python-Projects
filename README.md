# Python Application Portfolio

A collection of console-based applications developed in Python, demonstrating Object-Oriented Programming (OOP) design patterns, persistent file storage, and modular architecture.

---

## Projects Overview

### 1. [Student Management System](./student_management_system)
A command-line academic administration system designed to manage student records, course catalogs, enrollment mappings, grade records, and subject-wise attendance tracking with persistent text-file storage.

### 2. [Hangman Game](./hangman)
An interactive word-guessing game featuring categorized word banks, multiple input evaluation modes (single letters, substrings, and full-word guesses), scoring mechanics, and automated session audit logging.

---

## Execution Instructions

To run either application, navigate to the target project directory and execute the entry script:

### Student Management System
```bash
cd student_management_system
python main.py
```

### Hangman Game
```bash
cd hangman
python main.py
```
